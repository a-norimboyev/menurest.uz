# MENUREST.UZ (V2)

Multi-restaurant QR menu and SaaS dining platform.

## Architecture & Core Modules
- **Client QR Menu:** Mobile-first responsive interface (390px - 1440px).
- **Kitchen Display System (KDS):** Real-time order dispatching and status tracking.
- **Waiter & Table Operations:** Atomic waiter calls, table occupancy, and cleaning cycles.
- **Cashier & Shift Management:** Accurate visit billing, partial payments, and optimistic concurrency locks.
